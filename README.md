# NYC Traffic Accident Analysis (Excel Project)

## Project Overview
This project was completed as part of an analytics taskforce initiative for the New York City Police Department (NYPD). The objective was to analyze traffic accident data from January 1, 2021 to April 9, 2023 to identify patterns and trends that can help improve public safety and reduce future accidents.

---

## Business Objective
- Identify seasonal patterns in traffic collisions  
- Analyze weekly and hourly trends  
- Examine key contributing factors causing accidents  
- Provide data-driven insights for accident prevention  

---

## Tools and Skills Used
- Microsoft Excel  
- Pivot Tables and Pivot Charts  
- Data Cleaning and Transformation  
- Calculated Columns  
- Data Aggregation and Summarization

# REPORT 3: CONTRIBUTING FACTORS ANALYSIS

## Objective
Identify the main causes of traffic accidents.

## Key Findings
- Driver Inattention/Distraction is the leading cause  
- Failure to Yield Right-of-Way and Unsafe Speed are significant contributors  
- Traffic Control Disregarded shows high risk severity
